# OCR 修正清单（档案目录）

> 扫描 OCR 生成的档案目录常见错误修正。**易识别错误→自动修正；不确定→黄色高亮供人工核对。**
> 各单位有各自的 OCR 错字积累，处理新单位时先从源文件核对并补充本清单。

## 一、通用 OCR 通病

| 类型 | 表现 | 修复 |
|------|------|------|
| 数字误识 | `J`→`0`、`C`→`0`、`S`→`5`、`O`→`0`、`I`→`1` | 视上下文 |
| 文字误识 | `夫于/关玩`→`关于`、`办斤/办公斤`→`办公厅`、`省计厅`→`省审计厅` | 常见词 |
| 全角/半角括号混用 | `［］〔〕「」【】` | → 半角 `[]`（文号）；题名圆括号→全角 `（）` |
| 列偏移 | A 空但 B 有数字 | 按 B 起提取 |
| 序号前带符号 | `·007`、`-007` | 去符号后补 3 位 |
| 页数混入残留 | `002 0`、`0060-` | 去残留 → 3 位 |
| 件号误识 | `245`→`345` 等 | 按上下文/前后件号核对 |

## 二、档号

- 分隔符统一 `·`：`ws-`/`ws。`/`ws,`/`ws:`/`ws、`/`ws `空格/`ws=`/`ws→`/`ws.` → `ws·`
- 单位误识：`1012-s·`/`1012-vs·`→`1012-ws·`；`1001-IS`→`1001-WS`；`-030-`→`-D30-`；`1012-s`→`1012-ws`
- 年份：`200S`→`2006`；`1996--`→`1996-y-`；`2007`→`2006`（按上下文核对）
- 补缺件号：`-y-`→`-y-0001`（用序号补 4 位）
- 修正 `-·0008`→`-0008`
- 格式统一：小写、件号 4 位补零

## 八、备注

OCR 残留（`0|0|2|4`、`UU|S`、`GuGく`、`00UUU`、`8中中`、`0八9` 等，不含 ≥2 个不同汉字）全部清空。

## 使用注意

- 本清单是**积累型**资源：处理新单位/新批次时，若发现新 OCR 错字，确认后追加到对应单位小节。
- 自动修正范围限定在**高置信度**的固定错字；涉及语义判断的（如同形错字但可能不同词）一律黄色高亮供人工核对。
