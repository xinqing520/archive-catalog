# 档案目录输出格式与字段规范

> 统一格式，与县委办/统战部/总工会成品一致。

## 一、成品结构

### 带档号（9 列，归档文件目录）
```
行1 : 档案文件目录        （合并 A:I，宋体 16，居中）
行2 : 保管期限：永久      （合并 F:I，宋体 12，居中）
行3 : 序号 | 档 号 | 文号 | 责任者 | 题 名 | 日 期 | 密级 | 页数 | 备注
行4+: 数据行（宋体 12，全边框，居中，自动换行，行高按内容自动）
```
- Sheet 命名：`{年份}{期限}`（永久）或 `{年份}-{期限}`（30年/10年），如 `2006永久`、`2008-30年`
- 期限排序：永久在前，其余按出现顺序
- 冻结 `A4`

### 无档号（7 列，卷内目录/件级）
```
行1 : 档 案 文 件 目 录    （合并 A:G，宋体 14，居中）
行2 : {单位} 保管期限 {期限} 机构（问题）{机构} {N}件 （合并 A:G，宋体 11，下边框）
行3 : 件号|责任者|文号|题名|日期|页数|备注
行4+: 数据行（宋体 11，全边框，居中，自动换行）
```

## 三、字段规范

| 字段 | 规则 |
|------|------|
| **序号** | 3 位 `001`，年内连续，按卷内/原顺序升序 |
| **档号** | `全宗号-ws·年度-期限码-件号`，如 `1031-ws·2019-d30-0029`。小写、`·` 无空格、件号 4 位补零；有则填、无则空、**不编造** |
| **文号** | 方括号 `［］〔〕「」【】`→半角 `[]`；圆括号 `()`→全角 `（）`；去所有空白；明显 OCR 错修正 |
| **责任者** | 去空白；多机构间分隔统一全角分号；多机构间补空格（不拆 `办公室`/`委员会` 完整后缀） |
| **题名** | 去所有空格、开头残留标点；方括号→半角、圆括号→全角；`《》` 配对（开多于闭则补闭号）；OCR 修正 |
| **日期** | 8 位整数 `YYYYMMDD`；仅到年 `YYYY0000`、仅到月 `YYYYMM00` 合法 |
| **密级** | 原文保留，去空格 |
| **页数** | 3 位 `003`；区间两端各补 3 位 `001-004`；保留原字符串格式 |
| **备注** | 去空格；OCR 残留（不含 ≥2 个不同汉字）清空 |

## 四、日期异常处理规则

| 形态 | 例子 | 处理 |
|------|------|------|
| 8 位合法 | `20180927`、`20110000`、`20110300` | 保留 |
| **9 位占位（00月00日）** | `201000000`、`202000000` | **一律留空**并取消高亮 |
| 8 位月份非法 | `20188927`（89月） | 单独询问用户，通常按最可能日期改（`20180927`） |
| 7 位缺位 | `2019000`、`2019012` | 单独询问用户补位（`20190000` / `20190120`） |

> 9 位占位日期「留空」是用户确认的规则，处理新批次时直接应用；月份非法/缺位的 8/7 位日期必须询问用户，不擅自猜测。

## 五、不确定项高亮

- 黄色填充：`PatternFill(start_color="FFFF00", end_color="FFFF00", fill_type="solid")`
- 仅对**未确认的新增批次**应用；用户核对后取消高亮即视为已确认
- 高亮 key：`(年份, 期限码大写, 件号)` → 字段名集合（如 `{"文号"}`、`{"日期"}`）
- 已确认成品不得重放旧高亮

## 六、行高估算

```python
def est_lines(text, width):
    if not text:
        return 1
    units = sum(2 if ord(ch) > 0x2E80 else 1 for ch in str(text))
    per_line = max(1, int(width * 0.8))
    return max(1, math.ceil(units / per_line))

def row_height_calc(vals):
    max_lines = max(est_lines(v, COL_W[col]) for col, v in enumerate(vals, 1) if v)
    return max(45.0, max_lines * 17 + 4)
```

## 七、校验清单

1. Sheet 结构 & 件数（各 Sheet + 总计）
2. 序号年内连续、无缺号、无重复
3. 档号全部符合规范、唯一无重复
4. 无残留黄色高亮
5. 日期全部合法（8 位、月/日 01-12/00-31 或 00）
6. 页数为纯数字或 `ddd-ddd` 区间
7. 与备份对比：真实内容差异仅预期改动
