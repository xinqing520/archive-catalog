# 格式差异应对：面对陌生/不同格式的源文件

> 别人发来的档案目录**不总是标准格式**——可能是老版 Excel（`.xls`）、Word 目录（`.docx`）、压缩包（`.zip`），列顺序不同、表头位置不同、分段方式不同、无档号、列偏移等。本文件给出**拿到任何文件后如何应对**的系统化策略。

## 核心原则

1. **先探查，再动手**：任何格式都先读进来「看一眼」，别急着写解析逻辑
2. **不猜、不编造**：无法确认的字段留空或高亮，让用户确认，绝不脑补
3. **能适配就适配，适配不了就问**：固定的表头映射、列偏移等可自动适配；涉及语义/缺项的必须问
4. **先产出再校验**：处理完跑一遍「最终校验清单」，用数据证明没弄错

## 第一步：探查文件（拿到任何文件先做）

```python
import openpyxl
wb = openpyxl.load_workbook(path)        # .xlsx / .xlsm
print("Sheets:", wb.sheetnames)          # 可能多 Sheet，逐个看
ws = wb.worksheets[0]
for i, row in enumerate(ws.iter_rows(min_row=1, max_row=8, values_only=True)):
    print(i + 1, [str(v)[:18] if v is not None else "" for v in row])
```

- **`.xls`（老格式）**：openpyxl 读不了，需先转 `.xlsx`（用 Excel / LibreOffice / `xls2xlsx` 工具），或读时用 `xlrd`
- **`.docx`（Word 目录）**：用 `python-docx` 读表格，表通常为「单位|机构|保管期限|起止件号|档号页数|备注」
- **`.zip`**：解压后里面可能是多个 Excel，逐个探查
- **`.pdf` / 图片**：先 OCR 转成 Excel 再做（不是本 skill 的解析范围，需外部 OCR 工具）

## 第二步：判断源文件类型（三选一）

| 判据 | 类型 |
|------|------|
| 表头含「档号」，档号形如 `全宗号-WS·2006-Y-001` | **归档文件目录**（件级带档号） |
| 有「×××-Y-×××」卷号行作分节，卷内有表头+数据 | **卷内文件目录**（件级无档号） |
| 表头为「案卷号|题名|年度|…」 | **案卷目录**（卷级） |

> 判据落在**表头关键词**（档号/题名/案卷号），不依赖文件名。文件名可能是用户随手起的（`1。1.xlsx`、`转 Excel 2013.xlsx`），不可信。

## 第三步：识别并适配常见格式变体

### A. 列偏移（最常见的坑）
| 现象 | 识别 | 适配 |
|------|------|------|
| A 列空、B 列才有数字 | 表头行后某行 A 为空但 B 是数字 | 字段映射从 B 起算 |
| 首列是`·007`/`-007`/`11` | 序号带符号或不补零 | 去符号后 `zfill(3)` |

### B. 表头位置/形状不同
| 现象 | 识别 | 适配 |
|------|------|------|
| 表头不在第 1 行 | 前几行是「归档文件目录」「×××档案」等标题 | 扫描直到某行含「档号/题名/案卷号」即视为表头 |
| 表头列名不全 | 某列无表头字 | 按顺序推断（第3列=文号、第4列=责任者…），但**存疑则高亮** |
| 表头重复出现 | 每段目录前都有一行表头 | 每遇到表头行都重新建立字段映射 |

### C. 分段方式不同
| 现象 | 识别 | 适配 |
|------|------|------|
| 按「保管期限」分段 | 行含「保管期限：永久/30年」 | 记住当前期限，数据行归属之 |
| 按卷号分节（卷内目录） | 行含「×××-Y-×××」 | 每卷一节，卷内序号连续 |
| 按「节标题」分段（县委办） | 段标题（机构/问题分类） | 段标题后的行归当前段，跨段防污染 |
| 多段表格间有 OCR 残留行 | 段间夹杂乱码行 | 无内容（不含中文/数字）的跳过 |

### D. 无档号 / 缺档号
| 现象 | 处理 |
|------|------|
| 整表无档号列 | 档号列留空，不编造 |
| 个别行档号缺失 | 档号留空，序号/日期等照填 |

### E. 列数不同（9列 / 7列）
| 列数 | 对应 | 输出 |
|------|------|------|
| 9 列（含档号） | 序号|档号|文号|责任者|题名|日期|密级|页数|备注 | 按年度×期限分 Sheet |
| 7 列（无档号） | 件号|责任者|文号|题名|日期|页数|备注 | 按年度分 Sheet |

### F. 日期格式五花八门
| 源格式 | 处理 |
|--------|------|
| `20180101`（8位） | 保留 |
| `2018-01-01` / `2018/1/1` | 转 `20180101` |
| `2018年1月1日` | 转 `20180101` |
| Excel 日期序列号（`43101`） | 先转字符串再规范 |
| `2018`（仅年） | 转 `20180000` |
| 9位/7位/非法 | 按 `format.md` 日期分级规则处理 |

### G. 多 Sheet / 多文件
| 情况 | 处理 |
|------|------|
| 源文件多 Sheet（分年度） | 逐个 Sheet 解析后合并 |
| 源文件是 zip（含多个 Excel） | 全部解出、逐个解析 |
| 同档号分存多批 | 跨文件同卷续接合并，同序号重复保留先出现者 |

## 第四步：决定「自动改」还是「问用户」

```
能确认是固定 OCR 错字（高置信度）  → 自动修正（用 ocr-fixes.md 清单）
格式差异（列偏移/表头/分段/日期格式）→ 自动适配
缺项/缺号/档号缺失               → 留空，不编造
语义不确定（同形错字、疑重复）     → 黄色高亮，用户核对后取消
涉及猜测（月份非法日期、补位）     → 单独询问用户
```

## 第五步：产出后校验

跑 `format.md` 的「校验清单」：Sheet 结构、件数、序号连续、档号唯一规范、无残留高亮、日期/页数合法。**用数据证明处理正确**，而不是"看起来对了"。

## 常见的「以为懂其实要问」陷阱

- 日期 `20188927`（89月）→ 是 `20180927` 还是别的？**问**
- 文号 `[20156]号` → 是 `[2015]` 还是 `[2016]`？**问**或高亮
- 题名「实施活动」→ 是「实施方案」还是原样？**问**或高亮
- 档号缺失 → 不能靠序号推档号，**留空**
- 两个相邻件号完全重复 → 是重复录入还是两件？**高亮**给用户定
