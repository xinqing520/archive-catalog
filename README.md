# 🗂️ archive-catalog

**档案电子目录批处理 skill** —— 把 OCR 扫描生成的原始档案目录，解析、规范化、构建为统一格式成品，支持分批并入总目录与最终校验。

适用于**机关事业单位**（县委办、总工会、宣传部、统战部等）档案数字化整理：把「扫描件 → OCR 出的 Excel」变成规范、可归档、可合并的总目录。

---

## ✨ 功能特性

- **自动判别源文件类型**：归档文件目录（带档号）/ 卷内文件目录（无档号）/ 案卷目录（卷级）
- **容错处理各种格式**：列偏移、表头移位、多段乱码、无档号、日期格式多样、`.xls`/`.docx`/`.zip` 多格式源——见 [格式差异应对](references/format-adaptation.md)
- **字段规范化**：档号统一 `全宗号-ws·年度-期限码-件号`（小写、`·` 分隔、件号 4 位）；文号/题名/责任者/页数/日期逐字段清理 OCR 错字
- **日期异常分级处理**：
  | 形态 | 处理 |
  |------|------|
  | 9 位占位日期（`201000000` / `202000000`） | 一律留空 |
  | 8 位月份非法（`20188927`） | 询问用户确认 |
  | 7 位缺位（`2019000` / `2019012`） | 询问用户补位 |
- **不确定项黄色高亮**：无法自动判断的标黄，人工核对后取消即视为确认
- **统一输出格式**：9 列（带档号）/ 7 列（无档号），宋体、全边框、居中、自动换行、行高自适应
- **批次并入总目录**：基于已确认成品并入新批次，**不从原始源重建**（保留人工确认，不重放已取消高亮）
- **最终校验**：序号连续、档号唯一规范、无残留高亮、日期/页数合法性全查
- **通用脚本模板**：`scripts/norm_common.py` 复制即用

## 🚀 快速开始

### 场景一：构建新成品

```
把 OCR 源文件（如 1。1.xlsx）放入项目目录
→ 用 Claude Code 打开该项目 → 说「处理档案目录」
→ skill 自动识别类型、解析、规范化、生成统一格式成品
```

### 场景二：并入新批次

```bash
# 1. 先备份已确认成品
cp 安福县总工会.xlsx 安福县总工会_bak.xlsx

# 2. 并入新批次（只用新文件，勿重跑旧批）
python _build_归档.py 安福县总工会.xlsx 新批次.xlsx
```

> ⚠️ **关键**：合并新批次必须基于**已确认的成品**，不得从原始源重新生成——否则会把用户已取消的高亮全部重放。

### 场景三：用规范化脚本模板

```bash
python scripts/norm_common.py   # 运行自测（10 项全过）
```

```python
from norm_common import norm_dh, norm_tm, date_ok
norm_dh("1031-WS ·2006-Y-001")     # -> "1031-ws·2006-y-0001"
date_ok("20188927")                # -> (False, "月份/日期非法(89月27日)")
```

## 🧠 核心规则速查

| 项 | 规范 |
|----|------|
| 档号格式 | `全宗号-ws·年度-期限码-件号`，如 `1031-ws·2019-d30-0029`（小写、`·` 无空格、件号 4 位） |
| 期限码 | `y`=永久、`d30`=30年、`d10`=10年 |
| 全宗号 | 按单位参数化（总工会 1031 / 县委办 1001 / 统战部 1012） |
| 日期 | 8 位 `YYYYMMDD`；仅到年 `YYYY0000`、到月 `YYYYMM00` 合法 |
| 处理原则 | 纯序号无内容→删；完整缺项→留；易识别错→自动修；不确定→🟡 高亮 |
| 档号缺失 | 留空，不编造 |

## 🔧 如何扩展（新增单位 / 新格式）

1. **新增单位**：处理新单位时核对 OCR 错字 → 追加到 `references/ocr-fixes.md` 对应小节（或新建该单位小节）；档号规范化时传入该单位全宗号
2. **新增格式变体**：把新的格式差异（列偏移变体、分段方式等）记录到 `references/format-adaptation.md` 对应小节
3. **新增规范化规则**：追加到 `scripts/norm_common.py` 的替换列表，并补充自测用例

> OCR 修正清单与格式差异清单都是**积累型**资源，越用越全。

## ❓ 常见问题

**Q：源文件是 .xls（老版 Excel）能读吗？**
A：openpyxl 不能直接读 `.xls`，先转成 `.xlsx`（Excel 另存 / LibreOffice / xls2xlsx 工具），或让用户提供 `.xlsx`。

**Q：别人发的文件没有档号怎么办？**
A：档号列留空，**不编造**。文件缺档号是正常情况，按年度分 Sheet 即可。

**Q：日期只有年份怎么办？**
A：转 `YYYY0000`（如 `2018` → `20180000`），属于合法日期。

**Q：9 位日期（如 201000000）？**
A：按规则一律留空。

**Q：两个相邻件完全一样，是重复吗？**
A：不确定，黄色高亮后由人工核对决定。

**Q：合并后高亮又冒出来了？**
A：说明用了从原始源重建的方式。应基于已确认成品并入，只对新批次应用高亮。
