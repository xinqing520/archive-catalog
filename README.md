# archive-catalog · 档案电子目录批处理 skill

Claude Code skill：处理「档案电子目录」——把 OCR 生成的源 Excel 解析、规范化、构建为统一格式成品，支持分批并入总目录与最终校验。

## 功能

- **识别源文件**：归档文件目录（带档号）/ 卷内文件目录（无档号）/ 案卷目录（卷级）三种类型自动判别
- **提取数据行**：表头映射、列偏移处理、OCR 残留行过滤、跨文件同卷续接合并
- **字段规范化**：档号统一 `全宗号-ws·年度-期限码-件号`（小写、`·` 分隔、件号 4 位）；文号/题名/责任者/页数/日期逐字段规范
- **日期异常分级处理**：
  - 9 位占位日期（`201000000` / `202000000`）→ 一律留空
  - 8 位月份非法（`20188927`）→ 询问用户确认
  - 7 位缺位（`2019000` / `2019012`）→ 询问用户补位
- **通用规范化脚本**：`scripts/norm_common.py` 提供档号/文号/题名/责任者/页数/日期规范化函数（全宗号参数化），复制即用
- **不确定项黄色高亮**：供人工核对，取消高亮即视为确认
- **输出统一格式**：9 列（带档号）/ 7 列（无档号），宋体、全边框、居中、自动换行、行高自适应
- **批次并入总目录**：基于已确认成品并入，不从原始源重建（保留人工确认）
- **最终校验**：序号连续、档号唯一规范、无残留高亮、日期/页数合法性全查

## 安装

### 方式一：git clone（推荐）

```bash
git clone https://github.com/<your-username>/archive-catalog.git ~/.claude/skills/archive-catalog
```

### 方式二：手动复制

将本仓库 `archive-catalog` 目录整体复制到 `~/.claude/skills/` 下即可。

### 验证

Claude Code 会话中运行 `/skills` 看到 `archive-catalog` 即安装成功。之后说「处理档案目录」「合并总目录」「档号规范化」等即自动触发。

## 使用

```bash
# 构建/并入成品
python _build_归档.py 总目录.xlsx 新批次.xlsx

# 卷内目录从原始源构建
python _build_总工会.py 成品.xlsx 源文件.xlsx

# 规范化函数模板（复制到目标项目后 import 使用）
python scripts/norm_common.py   # 运行自测
```

> `_build_*.py` 脚本为各单位项目内积累的参考实现；`scripts/norm_common.py` 是通用规范化函数模板，可直接复制到目标项目。

## 目录结构

```
archive-catalog/
├── SKILL.md                  # 主流程（触发→识别→提取→规范化→输出→并入→校验）
├── references/
│   ├── format.md             # 输出格式模板、字段规范、日期/高亮规则
│   └── ocr-fixes.md          # OCR 修正清单（通用 + 各单位积累）
├── scripts/
│   └── norm_common.py        # 通用字段规范化函数模板（档号/文号/题名/责任者/页数/日期）
├── examples/
│   └── example.md            # 处理效果示例与典型 OCR 错例
├── README.md
├── LICENSE
└── .gitignore
```

## 如何扩展（新增单位）

1. 处理新单位时，从源文件核对 OCR 错字
2. 将确认的新修正追加到 `references/ocr-fixes.md` 对应小节（或新建该单位小节）
3. 全宗号在档号规范化时作为参数传入（常见：总工会 1031 / 县委办 1001 / 统战部 1012）
