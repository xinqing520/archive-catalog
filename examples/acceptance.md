# 档案目录验收流程

> 新单位/新批次处理完成后，按此流程验收，确保成品可用、可归档、可交接。

## 一、成品自检（处理方）

处理完成后，用 CLI 跑最终校验：

```bash
python scripts/archive_cli.py check 成品.xlsx
```

输出应无「问题」；若有，逐项处理：

| 问题 | 处理 |
|------|------|
| 序号缺号/重复 | 核对源文件，补序或确认 |
| 档号重复/不规范 | 检查档号规范化逻辑 |
| 残留高亮 | 人工核对后取消，或确认待处理 |
| 日期非法/缺位 | 按日期分级规则：占位留空、非法询问、缺位补位 |
| 页数格式异常 | 补 3 位或区间补位 |

## 二、人工核对（用户）

1. 打开成品，逐 Sheet 扫一眼
2. **黄色高亮项**逐条核对：确认的 → 取消高亮；要改的 → 改文字后取消高亮
3. 抽查档号、日期、题名是否与原文一致
4. 确认无误后，告知处理方「已确认」

> ⚠️ **确认的成品是权威**：后续并入新批次必须基于它，不得从原始源重建。

## 三、交接检查清单（新单位接手）

| 项 | 检查 |
|----|------|
| 源文件 | 是否齐全（按批次归档） |
| 成品 | 格式统一（9列/7列、宋体、边框、居中） |
| 档号 | 全部 `全宗号-ws·年度-期限-件号` 规范、唯一 |
| 日期 | 全部 8 位合法或留空（占位已清） |
| 高亮 | 无残留（或已确认待办） |
| 记录 | 处理日志 `examples/processing-log.md` 模板已填 |
| 备份 | 并入前备份文件保留 |

## 四、归档

- 成品 + 各批次源文件 + 处理日志 放入该单位目录
- 备份文件（`*_bak_*.xlsx`）保留一段时间再清理
- 在 `档案目录处理说明.md` 中更新单位状态表

## 五、已验收标记

- [ ] 成品自检通过
- [ ] 用户人工核对完成
- [ ] 交接清单逐项通过
- [ ] 归档完成
