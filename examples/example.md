# 处理示例

展示「档案电子目录」从 OCR 源文件到成品的处理效果，以及典型 OCR 错例的规范化结果。

## 一、源文件 → 成品

### 源文件（OCR 生成的归档文件目录，含噪音）

| 序号 | 档号 | 文号 | 责任者 | 题名 | 日期 | 页数 |
|------|------|------|--------|------|------|------|
| 007 | `1031-WS ·2006-Y-007` | `吉工字[2006]25事情` | `吉安市总工会` | 关于成立安福县总工会法律援助工作站的通知 | `20060000` | `006` |
| 010 | `1031-ws·2006-y-10` | `吉工民字[2010].2号` | `吉安市总保障部` | 关于转发《关于2011年厂务公开民主管理工作意见》的通知 | `201000000` | `8` |

### 规范化后（成品）

| 序号 | 档号 | 文号 | 责任者 | 题名 | 日期 | 页数 |
|------|------|------|--------|------|------|------|
| 007 | `1031-ws·2006-y-0007` | `吉工字[2006]25号` | 吉安市总工会 | 关于成立安福县总工会法律援助工作站的通知 | 20060000 | 006 |
| 010 | `1031-ws·2006-y-0010` | `吉工民字[2010]2号` | 吉安市总工会保障部 | 关于转发《关于2011年厂务公开民主管理工作意见》的通知 | *(留空)* | 008 |

**处理说明：**
- 档号：大写→小写、`·` 去空格、件号 1 位/2 位补为 4 位（`007`→`0007`、`10`→`0010`）
- 文号：`事情`→`号`；`].`→`]` 去误入点；件号 `[2010].2`→`[2010]2`
- 责任者：`吉安市总保障部`→`吉安市总工会保障部`
- 日期：`201000000`（9位占位）→ **留空**（按规则）
- 页数：`8`→`008` 补 3 位

## 二、典型 OCR 错例与修正

### 档号
```
1031-WS ·2006-Y-001   →  1031-ws·2006-y-0001
1012-s·1980-Y-11      →  1012-ws·1980-y-0011
1001-IS-2013          →  1001-ws·2013-?-0001（IS 误识需结合期限码核对）
200S                  →  2006
1996--                →  1996-y-
```

### 文号
```
安工字【2013】1号     →  安工字[2013]1号
赣工（【2009】39号    →  赣工[2009]39号
吉工民字[2010].2号    →  吉工民字[2010]2号
第22；                →  第22号；
［2013]               →  [2013]
（87)                 →  （87）
```

### 题名
```
关于20110年度考评的通知         →  关于2011年度考评的通知
关于选派劳模走江苏无锡休养的通知 →  （原样）
关于印发《工会体育活动经费开支暂行规定   →  印发《工会体育活动经费开支暂行规定》
抓管理。增效益                 →  抓管理、增效益
第8-11,14-15期                →  第8-11、14-15期
```

### 责任者
```
吉安市总保障部   →  吉安市总工会保障部
市统战部         →  市委统战部
地.区民宗局      →  地区民宗局
总工会人バ       →  总工会
```

### 日期（按分级规则处理）
```
20110000   保留（仅到年）
20110300   保留（仅到月）
20180927   保留（合法）
201000000  → 留空（9位占位）
202000000  → 留空（9位占位）
20188927   → 询问用户（89月非法），如确认改 20180927
2019000    → 询问用户（7位缺位），如确认改 20190000
2019012    → 询问用户（7位缺位），如确认改 20190120
```

### 页数
```
J06     →  006
·028    →  028
12      →  012
12-24   →  012-024
002 0   →  002（去残留）
```

### 备注（OCR 残留清空）
```
0|0|2|4   →  （清空）
UU|S      →  （清空）
00UUU     →  （清空）
8中中     →  （清空）
```

## 三、Sheet 划分

- **归档文件目录**（带档号）：按「年度×期限」分 Sheet —— `2006永久`、`2008-30年`、`2011-30年`
- **卷内文件目录**（无档号）：按「年度」分 Sheet —— `1983`、`1987`、`1990`
- **案卷目录**（卷级）：按原样保留为独立 Sheet —— `1968-1987`

## 四、批次并入总目录

```
# 并入前先备份
cp 安福县总工会.xlsx 安福县总工会_bak.xlsx

# 并入新批次（只用新文件，勿重跑旧批）
python _build_归档.py 安福县总工会.xlsx 新批次.xlsx

# 处理后校验：无残留占位日期/非法日期/黄色高亮
```

> ⚠️ 合并新批次**必须基于已确认成品**，不得从原始源重建，否则会重放用户已取消的高亮。
